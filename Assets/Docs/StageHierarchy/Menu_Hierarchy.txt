Title: Stage_Menu - Hierarchy & Wiring Guide
SceneName: Stage_Menu
Purpose: 메인 메뉴(새 게임/계속/설정/종료)

1) 하이라키어 최종 구조도
1. Canvas (UI/Canvas) [Components: Canvas, CanvasScaler, GraphicRaycaster]
  1.1 Panel_BG (UI/Image) [Components: Image]
  1.2 MainMenu (Empty) [Components: MainMenuUI]
    1.2.1 Buttons (Empty) [Components: -]
      1.2.1.1 Button_New (UI/Button) [Components: Button]
      1.2.1.2 Button_Continue (UI/Button) [Components: Button]
      1.2.1.3 Button_Settings (UI/Button) [Components: Button]
      1.2.1.4 Button_Quit (UI/Button) [Components: Button]
  1.3 Panel_Settings (Empty) [Components: SettingsPanel(optional), Set Inactive]

2) 하이라키어 제작 절차(생성 경로 포함)
2.1 (1) Canvas
  - 생성 경로: GameObject > UI > Canvas
  - 자동 포함: CanvasScaler, GraphicRaycaster
2.2 (1.1) Panel_BG
  - 생성 경로: Canvas 하위, GameObject > UI > Image
2.3 (1.2) MainMenu
  - 생성 경로: Canvas 하위, GameObject > Create Empty (이름: MainMenu)
  - Add Component: MainMenuUI
2.4 (1.2.1) Buttons
  - 생성 경로: MainMenu 하위, GameObject > Create Empty (이름: Buttons)
2.5 (1.2.1.1~1.2.1.4) 버튼 4개
  - 생성 경로: Buttons 하위, GameObject > UI > Button (이름: Button_New/Continue/Settings/Quit)
2.6 (1.3) Panel_Settings
  - 생성 경로: Canvas 하위, GameObject > Create Empty (이름: Panel_Settings)
  - Add Component: SettingsPanel(optional), SetActive(false)

3) 인스펙터 설정(오브젝트별 핵심 값)
- CanvasScaler: UI Scale Mode=Scale With Screen Size, Reference=1920x1080, Match=0.5
- Panel_BG(Image): Color #000000, Alpha=0.65, RectTransform Stretch(모두 0)
- Buttons OnClick:
  - Button_New → MainMenuUI.OnClickNewGame()
  - Button_Continue → MainMenuUI.OnClickContinue()
  - Button_Settings → (후속) MainMenuUI.OnClickSettings() 또는 비활성화
  - Button_Quit → MainMenuUI.OnClickQuit()

4) Components & Wiring(참조/이벤트 배선)
- MainMenuUI가 OnClick 이벤트를 수신해 StageChangeRequested 발행
- Panel_Settings는 SettingsPanel 구현 시 연결

5) Build Settings(Scenes In Build)
- Core(최상단), Stage_Menu, Stage_Front 등록

6) Tests(기능 검증)
- 메뉴 표시, 버튼 3종 동작, New 클릭 시 Front 전환(페이드)
