Title: MainMenu - Hierarchy & Wiring Guide (Continue Enabled)
SceneName: MainMenu
Purpose: 새 게임/이어하기/옵션/종료 제공

1) 하이라키
- UI/MainCanvas(Canvas)
  - Buttons
    - Button_New
    - Button_Continue
    - Button_Options
    - Button_Quit

2) 제작 절차
- Button_Continue 활성 조건: ISaveService.HasAnySave() == true 일 때만 SetActive(true)
- Click: ISaveService.TryLoadAll() 성공 시 SaveService.GetLastStageIdOr(StageIds.Stage1) 로 이동 요청

3) 체크리스트
- [ ] SaveService가 Core 씬에서 살아있는지 확인
- [ ] 이어하기 비표시 조건 정확(저장 없음)
