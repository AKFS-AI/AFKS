Title: Stage1 - Hierarchy & Wiring Guide
SceneName: Stage1
Purpose: 병원 앞(체인 해금→문 열림→Stage2). 월드 스프라이트 기반 체인 상호작용 + 배경 전환.

1) 하이라키어 최종 구조도(월드 모드)
- World_Empty(-)
  - BG_2D/Sprite(SpriteRenderer, Stage1Controller)
- Interaction_Empty(-)
  - Hotspots_Empty(-)
    - Chain_Empty(BoxCollider2D, ChainController)
    - Door_Empty(HotspotMove, BoxCollider2D)
- Services_Empty(-)
  - StageRoot_Empty(StageRoot)
- UI_Empty(-)
  - MainCanvas_UI/Canvas(Canvas, CanvasScaler, GraphicRaycaster)
    - CloseupPanel_UI/Image(Image, CloseupViewer)
- EventSystem_UI/Event System(-)

2) 하이라키어 제작 절차(월드 모드)
2.1 (1) World_Empty
  - 생성 경로: GameObject > Create Empty (이름: World)
  - Add Component: 없음
2.2 (1.1) BG_2D/Sprite
  - 생성 경로: 2D Object > Sprite (부모: World)
  - Add Component: SpriteRenderer, Stage1Controller
2.3 (2) Interaction_Empty
  - 생성 경로: GameObject > Create Empty (부모: 루트)
  - Add Component: 없음
2.4 (2.1) Hotspots_Empty
  - 생성 경로: GameObject > Create Empty (부모: Interaction)
  - Add Component: 없음
2.5 (2.1.1) Chain_Empty
  - 생성 경로: GameObject > Create Empty (부모: Hotspots)
  - Add Component: BoxCollider2D, ChainController
2.6 (2.1.2) Door_Empty
  - 생성 경로: GameObject > Create Empty (부모: Hotspots)
  - Add Component: BoxCollider2D, HotspotMove
2.7 (3) Services_Empty
  - 생성 경로: GameObject > Create Empty (부모: 루트)
  - Add Component: 없음
2.8 (3.1) StageRoot_Empty
  - 생성 경로: GameObject > Create Empty (부모: Services)
  - Add Component: StageRoot
2.9 (4) UI_Empty
  - 생성 경로: GameObject > Create Empty (부모: 루트)
  - Add Component: 없음
2.10 (4.1) MainCanvas_UI/Canvas
  - 생성 경로: UI > Canvas (부모: UI)
  - Add Component: Canvas, CanvasScaler, GraphicRaycaster
2.11 (4.1.1) CloseupPanel_UI/Image
  - 생성 경로: UI > Image (부모: MainCanvas)
  - Add Component: Image, CloseupViewer
2.12 (5) EventSystem_UI/Event System
  - 생성 경로: UI > Event System (부모: 루트)
  - Add Component: EventSystem

3) 인스펙터 설정(핵심 값)
- BG(SpriteRenderer)
  - Sprite = StageBG_1_1 (기본 상태)
  - Order in Layer = 0
- BG(Stage1Controller)
  - 기본 배경 = StageBG_1_1
  - 해금 배경 = StageBG_1_2
  - 체인 오버레이 = Chain_Empty
  - 문 핫스팟 = Door_Empty
- Chain(BoxCollider2D)
  - Size = 체인 영역 (예: 2, 1)
  - Is Trigger = On
- Chain(ChainController)
  - 클릭 횟수 = 3
  - 해금 시 배경 교체 = On
  - 체인 제거 = On
- Door(BoxCollider2D)
  - Size = 문 영역 (예: 3, 2)
  - Is Trigger = On
- Door(HotspotMove)
  - 목표 스테이지 ID = Stage2
  - 디버그 로그 = Off
- MainCanvas(Canvas)
  - Render Mode = Screen Space - Overlay
  - Sort Order = 0
- MainCanvas(CanvasScaler)
  - Reference Resolution = 1920x1080
  - Screen Match Mode = Match Width Or Height
  - Match = 1 (Height)
- CloseupPanel(Image)
  - Color = White
  - Preserve Aspect = On
  - Raycast Target = Off

4) Components & Wiring
- Chain(ChainController).OnChainUnlocked → BG(Stage1Controller).UnlockStage
- Chain(ChainController).OnChainUnlocked → Door(BoxCollider2D).enabled = true
- Chain(ChainController).OnChainUnlocked → Chain(BoxCollider2D).enabled = false
- Door(HotspotMove).OnClick → Stage2 전환
- StageRoot.OnStageActivated → BG(Stage1Controller).InitializeStage

5) Build Settings
- 순서: 1) Core  2) MainMenu  3) Stage1  4) Stage2

6) Tests
- 체인 클릭 → 흔들림 애니메이션 → 3회 클릭 시 해금
- 체인 해금 → 배경 1_2로 교체 + 체인 제거 + 문 활성화
- 문 클릭 → Stage2 전환 OK, 연타 시 1회만 동작

8) 체인 상호작용 상세
- 체인 클릭 시: 체인 흔들림 애니메이션 + 클릭 횟수 카운트
- 3회 클릭 시: 체인 잠금 해제 → 체인 제거 → 배경 1_2로 교체 → 문 활성화
- 체인 해금 상태는 SaveService에 저장되어 게임 재시작 시 유지
- 체인 해금 후 메뉴 배경은 자동으로 1_2로 미러링
