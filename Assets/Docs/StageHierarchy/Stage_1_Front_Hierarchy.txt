3) 인스펙터 설정(핵심 값)
- BG(SpriteRenderer)
  - Sprite = StageBG_1_1 (기본 상태)
  - Order in Layer = 0
- BG(Stage1Controller)
  - defaultBackground = StageBG_1_1
  - unlockedBackground = StageBG_1_2(옵션)
- ChainTop/ChainBottom(SpriteRenderer)
  - sortingOrder = 1, color = White
- ChainTop/ChainBottom(BoxCollider2D)
  - Size = (예: Top 1.4×0.3, Bottom 1.4×0.6), Is Trigger=On
- ChainTop/ChainBottom(ClickHandler)
  - clickable = false(초기, 줌 후 EnableInteractableEffect로 true)
- ChainTop/ChainBottom(ChainAnimationController)
  - shakeDuration=0.25, shakeIntensity=0.05, breakDuration=1.0, breakFallDistance=0.8
- Door(BoxCollider2D)
  - Size = (예: 4, 4), Is Trigger=On
- Door(ClickToEventRouter)
  - objectId = "Door"
- Door(CameraZoomEffect)
  - zoomDuration=1.5, targetOrthographicSize=3.0, targetPosition=(0,-1,-10)
- Door(HotspotMove)
  - targetStageId = "Stage2", manualTriggerOnly = On
- MainCanvas(Canvas)
  - Render Mode = Screen Space - Overlay
  - Sort Order = 0
- MainCanvas(CanvasScaler)
  - Reference Resolution = 1920x1080
  - Screen Match Mode = Match Width Or Height
  - Match = 1 (Height)
- CloseupPanel(Image)
  - Color = White
  - Preserve Aspect = On
  - Raycast Target = Off

4) Components & Wiring
- 라우팅: ClickHandler → ClickToEventRouter → StageEventSystem.OnObjectClicked(objectId)
- StageEventSystem
  - LoadFromDefinition(Stage1Definition)
  - Execute 완료 시 StageEvent.ApplyEffects(system)
  - 유틸: GetClickCount/DoesClickHistoryMatch/SetObjectInteractable
- StageDefinition(Stage1Definition)
  - Event[0] ZoomEvent
    - trigger: Click on "Door"
    - effects: EnableInteractable("ChainTop", true), EnableInteractable("ChainBottom", true)
  - Event[1] ClickEvent "체인 분리"
    - trigger: Click on "ChainTop","ChainBottom"
    - conditions: AggregateClickCount(["ChainTop","ChainBottom"], >=5)
    - effects: ChainShakeThenBreakEffect, autoProceed=true
  - Event[2] ClickEvent "문 클릭 → 다음 스테이지"
    - trigger: Click on "Door"
    - conditions: AggregateClickCount(["ChainTop","ChainBottom"], >=5)
    - effects: StageTransitionEffect("Stage2")
