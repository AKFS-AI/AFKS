2) 하이라키어 제작 절차(생성 경로 포함)
- 1) 컨테이너 생성
  - World_Empty, Interaction_Empty, UI_Empty, Services_Empty (Create Empty)

- 2) 배경 생성
  - BG_2D/Sprite(SpriteRenderer)
  - 생성 경로: GameObject > 2D Object > Sprite

- 3) 핫스팟 컨테이너 및 DoorZoom 생성
  - Hotspots_Empty 생성(부모=Interaction)
  - DoorZoom_Empty(HotspotInspect, BoxCollider2D) 생성
    - 생성 경로: GameObject > Create Empty
    - BoxCollider2D 추가, 영역을 클릭 가능 범위로 조정
    - HotspotInspect 추가: 클릭 시 UI/MainCanvas에 CloseupPanel 소환(또는 활성)

- 4) UI 캔버스 및 이벤트 시스템 생성
  - MainCanvas_UI/Canvas(Canvas, CanvasScaler, GraphicRaycaster)
    - 생성 경로: GameObject > UI > Canvas
    - Canvas Scaler: 1920x1080, Match 1.0(Height)
  - EventSystem_UI/Event System
    - 생성 경로: GameObject > UI > Event System

- 5) CloseupPanel 프리팹 제작
  - CloseupPanel_Empty(CanvasGroup, ChainCloseupController, CloseupPanelAutoWire)
    - 생성 경로: GameObject > Create Empty (부모=MainCanvas)
    - RectTransform: 풀 스트레치(Left/Right/Top/Bottom=0)
  - CloseupImage_UI/Image(Image, AspectRatioFitter)
    - 생성 경로: GameObject > UI > Image (부모=CloseupPanel)
    - Image: Preserve Aspect=On, AspectRatioFitter: EnvelopeParent 또는 FitInParent
  - ChainRoot_Empty → ChainTop_UI/Image, ChainBottom_UI/Image
  - ChainHotspot_UI/Image(Image, ChainHotspotUI)
    - ChainHotspotUI가 ChainCloseupController에 자동 연결됨(자동화 스크립트)
  - DoorHotspot_UI/Image(HotspotMoveUI) [초기 비활성]
    - HotspotMoveUI.targetStageId="Stage2", closeupRootToDestroy=CloseupPanel
  - 프리팹 저장: Assets/Prefabs/CloseupPanel.prefab

- 6) 배치/사용 방식 선택
  - 옵션 A: MainCanvas 하위에 CloseupPanel을 미리 배치(비활성) → DoorZoom 클릭 시 활성화
  - 옵션 B: DoorZoom에서 CloseupPanel 프리팹 Instantiate(권장, 중복 생성 가드 포함)

2-1) CloseupPanel(정밀 체인 클릭 + 전환)
- 목적: 해상도와 무관하게 체인 클릭 영역을 정확히 맞추고, 해금 후 문 UI로 바로 전환
- 구성
  - CloseupPanel (RectTransform 풀스트레치)
    - CanvasGroup + ChainCloseupController + CloseupPanelAutoWire
    - CloseupImage(Image, Preserve Aspect=On)
      - AspectRatioFitter: Mode=EnvelopeParent(화면 꽉 채우기, 크롭) 또는 FitInParent(레터박스)
    - ChainRoot(Empty)
      - ChainTop(Image), ChainBottom(Image) 2분할 구성(체인 상/하)
      - (선택) ChainRoot 또는 개별 이미지에 Animator 부착
    - ChainHotspot(Image 알파 0, Raycast On, ChainHotspotUI)
      - 클릭 시 ChainCloseupController.OnChainClicked 호출(자동 연결)
    - DoorHotspot(Image 알파 0, Raycast On, 초기 비활성)
      - HotspotMoveUI.targetStageId = "Stage2"
      - HotspotMoveUI.closeupRootToDestroy = MainCanvas(또는 CloseupPanel 루트)
  - 애니메이션(선택)
    - 체인 흔들림: Animator Trigger = "Shake" (상/하 동기 흔들림)
    - 체인 파괴: Animator Trigger = "Break" (상/하 비활성 또는 알파 0/파편 연출)
    - 애니 이벤트가 있으면 마지막 프레임에서 ChainCloseupController.OnBreakAnimationCompleted() 호출

생성 경로(메뉴) 가이드
1) MainCanvas_UI/Canvas 생성: GameObject > UI > Canvas
2) CloseupPanel 프리팹 배치 또는 Instantiate
3) CloseupImage 설정: Preserve Aspect On, AspectRatioFitter 설정
4) ChainHotspot 설정: Image α=0 + Button, OnClick → Controller.OnChainClicked
5) DoorHotspot 설정: Image α=0 + HotspotMoveUI, targetStageId="Stage2"

2-2) 체인 핫스팟 정규화 배치 방법
- 원본 클로즈업 텍스처 크기: (texW, texH)
- 체인 사각(pxX, pxY, pxW, pxH) 픽셀 기준으로 측정
- 정규화 앵커 값 계산:
  - nx = pxX / texW, ny = pxY / texH, nw = pxW / texW, nh = pxH / texH
  - ChainHotspot.anchorMin = (nx, ny)
  - ChainHotspot.anchorMax = (nx + nw, ny + nh)
  - ChainHotspot.offsetMin/Max = (0,0)
- 예시: texW=2048, texH=1024, 사각= x:768, y:384, w:512, h:256 → anchorMin=(0.375, 0.375), anchorMax=(0.625, 0.625)

2-3) 프리팹/배치 요약
- 배치: 각 씬의 UI/MainCanvas 하위에 CloseupPanel 배치(권장) 또는 DoorZoom 시 Instantiate
- 자동 연결: CloseupPanelAutoWire가 CloseupImage/ChainHotspot/ DoorHotspot/Animator를 자동 주입
- 상태 복원: ChainCloseupController.stateKey 기본값 사용(PlayerPrefs)

2-4) 줌(카메라 접근 느낌) 연출 설정
- DoorZoom(HotspotInspect) 인스펙터
  - UI 프리팹 소환 사용 = On
  - 소환할 패널 프리팹 = CloseupPanel 프리팹 참조
  - 대상 Canvas = UI/MainCanvas
  - 줌 연출(초) = 0.25 (권장 0.2~0.35)
  - 시작 스케일 = (0.3, 0.3)
  - Easing 曲선 = EaseInOut(기본)
- 효과: 클릭 위치에서 패널이 커지며 중앙으로 스무스하게 이동(알파 페이드 포함)

3) 인스펙터 설정(실제 인스펙터 순서)
- World/BG (2D/Sprite)
  - Transform: 기본값
  - Sprite Renderer
    - Sprite = <배경 스프라이트>
    - Draw Mode = Simple
  - 참고: UI/Image 대체는 특수 케이스에서만 사용

- Interaction/Hotspots/DoorZoom (Empty)
  - Transform: 클릭 영역 위치/크기에 맞게 조정
  - Box Collider 2D
    - Is Trigger = Off(기본)
    - Size = 환경에 맞게 설정
  - HotspotInspect(스크립트)
    - 클릭 시 UI/MainCanvas/CloseupPanel을 표시하도록 설정

- UI/MainCanvas (UI/Canvas)
  - Canvas
    - Render Mode = Screen Space - Overlay
  - Canvas Scaler
    - Reference Resolution = 1920 x 1080
    - Screen Match Mode = Match Width Or Height, Match = 1.0 (Height)
  - Graphic Raycaster = 기본값

- UI/MainCanvas/CloseupPanel
  - CloseupImage(Image)
    - Preserve Aspect = On
    - AspectRatioFitter.Mode = EnvelopeParent(가득 채우기) 또는 FitInParent(레터박스)
  - ChainHotspot(Image + ChainHotspotUI)
    - ChainHotspotUI가 컨트롤러에 자동 연결됨
    - anchorMin/Max: 정규화 값 설정(nx,ny,nw,nh) → offset=0
  - DoorHotspot(HotspotMoveUI)
    - targetStageId = "Stage2"
  - ChainCloseupController
    - bgLockedSprite=BG1_1, bgUnlockedSprite=BG1_2
    - chainRoot=ChainRoot, chainAnimator=(선택) Animator, requiredClicks=원하는 값
    - breakAnimSeconds=애니 이벤트 미사용 시만 폴백 대기

4) Components & Wiring(참조/이벤트 배선)
- DoorZoom(HotspotInspect).OnClick → UI/MainCanvas/CloseupPanel 활성/소환(클로즈업)
- ChainHotspotUI 클릭 → ChainCloseupController.OnChainClicked(클릭 누적/흔들림)
- ChainCloseupController: 누적=requiredClicks 도달 → Break 애니메이션 →
  - CloseupImage.sprite = BG1_2(해제 이미지)로 교체
  - ChainRoot 비활성화 → DoorHotspot 활성화
- DoorHotspot(HotspotMoveUI).OnClick → GameEvents.RaiseStageChangeRequested("Stage2") → CloseupPanel/프리팹 파괴(선택)
 - 디버깅: HotspotInspect.debugLog/CloseupPanelAutoWire.debugLog를 On으로 설정해 캔버스 선택, 프리팹 생성/재사용, BG 자동 매핑 결과 확인
