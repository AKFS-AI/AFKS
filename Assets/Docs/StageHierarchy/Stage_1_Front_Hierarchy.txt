Title: Stage1 - Hierarchy & Wiring Guide (World Trigger Edition)
SceneName: Stage1
Purpose: 병원 앞(문 접근 연출→월드 체인 해금→문 클릭 시 Stage2)

1) 하이라키어 최종 구조도(월드 기반)
- World_Empty(-)
  - BG_2D/Sprite(SpriteRenderer)
  - DoorZoomTarget_Empty(-)
  - ChainRoot_Empty(WorldChainController, Animator)
    - ChainTop(SpriteRenderer, BoxCollider2D)
    - ChainBottom(SpriteRenderer, BoxCollider2D)
- Interaction_Empty(-)
  - DoorArea(BoxCollider2D)
  - EmptyArea(BoxCollider2D)
  - DoorHotspot(HotspotMoveWorld, BoxCollider2D)
- Systems_Empty(-)
  - Stage1Flow(Stage1FlowController, CameraZoomCloseup)
  - AudioService(선택)

2) 하이라키어 제작 절차(월드)
- 1) 컨테이너 생성: World, Interaction, Systems
- 2) 배경 생성: BG_2D/Sprite(SpriteRenderer)
- 3) 카메라 줌 타깃: DoorZoomTarget(문 중앙 앞 위치)
- 4) 체인 생성: ChainRoot(Animator) 하위에 ChainTop/ChainBottom(SpriteRenderer+Collider)
- 5) 상호작용 콜라이더:
  - DoorArea(BoxCollider2D) → OnMouseDown에서 Stage1Flow.OnDoorClicked()
  - EmptyArea(BoxCollider2D) → OnMouseDown에서 Stage1Flow.OnEmptyClicked()
- 6) 문 핫스팟: DoorHotspot(HotspotMoveWorld) [초기 비활성]
- 7) 시스템: Stage1FlowController + CameraZoomCloseup 배치, 필드 연결

2-1) 체인/문 상호작용(월드)
- WorldChainController(requiredClicks=5, shakeLockSeconds=0.2, breakAnimSeconds=0.8)
- 브레이크 이벤트는 루트 Animator의 Animation Event로 호출(없으면 폴백 시간 경과 후 낙하)
- 루트에만 키프레임, 조각에는 위치/스케일 키 없음
- floorTarget: 계단 상면에 빈 오브젝트 배치(Y 착지 기준)

2-2) 줌(카메라 접근/이탈)
- Stage1FlowController.cameraZoom.ZoomIn(doorZoomTarget) / ZoomOut()
- 배경 5컷 전환: bgFar→bgNear1→...→bgNear5, stepDuration=0.15s, 발걸음 SFX 재생

3) 인스펙터 설정(실제 인스펙터 순서)
- World/BG (2D/Sprite)
  - Sprite Renderer: Sprite = <배경 스프라이트>
- World/ChainRoot (WorldChainController)
  - chainAnimator = 루트 Animator(Shake/Break 트리거)
  - topPiece = ChainTop, bottomPiece = ChainBottom, floorTarget = 계단 타깃
  - requiredClicks = 5
- Interaction/DoorHotspot (HotspotMoveWorld)
  - targetStageId = "Stage2" (초기 비활성 → 언락 후 활성화)
- Systems/Stage1Flow (Stage1FlowController)
  - cameraZoom, doorZoomTarget, backgroundRenderer, bgFar~bgNear5, worldChain, doorHotspot 연결
  - footstepClips = 발걸음 SFX들
- Systems/Stage1Flow (CameraZoomCloseup)
  - targetCamera = Main Camera(Orthographic), zoomOrthoSize = 연출값

4) Components & Wiring(월드)
- DoorArea.OnMouseDown → Stage1FlowController.OnDoorClicked()
- EmptyArea.OnMouseDown → Stage1FlowController.OnEmptyClicked()
- WorldChainController.Unlocked → Stage1FlowController에서 DoorHotspot 활성화
- DoorHotspot(HotspotMoveWorld) 클릭 → Stage2 전환

5) Build Settings(Scenes In Build)
- Core(최상단), MainMenu, Stage1, Stage2 등록

6) Tests(기능 검증)
- 문 클릭 → 카메라 줌 인 + 배경 5컷 순차 전환 + 발걸음 SFX
- 체인 5회 클릭 → 흔들림 → 브레이크 → 조각 계단 Y로 낙하 → 문 핫스팟 활성화
- 문 클릭 → Stage2 전환
- 근접 상태에서 빈 곳 클릭 → 배경 5컷 역순 전환 + 줌 아웃

7) 체크리스트
- [ ] DoorArea/EmptyArea 콜라이더 위치 확인, 클릭 호출 연결
- [ ] Stage1FlowController 필드 연결(cameraZoom, doorZoomTarget, backgroundRenderer, bgFar~bgNear5, worldChain, doorHotspot)
- [ ] WorldChainController: requiredClicks=5, 루트 Animator 트리거 이름 일치, 조각에 위치 키 없음
- [ ] floorTarget Y가 ChainTop/Bottom 시작점보다 아래
- [ ] DoorHotspot(HotspotMoveWorld).targetStageId="Stage2"

8) FAQ(문제 해결)
- 클릭 불가: Collider2D 레이어/카메라/정면 가림 확인
- 체인 안 떨어짐: 조각 위치 키 제거, floorTarget Y 위치 재설정, Animator 트리거 명 일치
- 문 전환 안 됨: Stage2 씬 ID, Build Settings 등록 확인
