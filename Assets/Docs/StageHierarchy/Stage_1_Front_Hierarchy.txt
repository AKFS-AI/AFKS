Title: Stage1 - Hierarchy & Wiring Guide
SceneName: Stage1
Purpose: 병원 앞(정문 클릭 → Lobby)

1) 하이라키어 최종 구조도
- World (Empty)
  - BG (2D/Sprite) [Components: SpriteRenderer]
- Interaction (Empty)
  - Hotspots (Empty) [Components: -]
    - DoorZoom (Empty) [Components: HotspotInspect, BoxCollider2D]
    - Chain (Empty) [Components: ChainUnlock, BoxCollider2D]
    - DoorMove (Empty) [Components: HotspotMove, BoxCollider2D]
- Services (Empty)
  - StageRoot (Empty) [Components: StageRoot]

2) 하이라키어 제작 절차(생성 경로 포함)
- 컨테이너 생성: World, Interaction, Services (모두 Empty)
- World/BG
  - 생성 경로: GameObject > 2D Object > Sprite (이름: BG)
  - Add Component: SpriteRenderer
  - 참고: UI/Image 대체는 특수 케이스에서만 사용(라벨 등 UI 혼합 필요 시)
- Interaction/Hotspots
  - 생성 경로: GameObject > Create Empty (이름: Hotspots)
  - 자식 DoorZoom: Create Empty → Add Component: BoxCollider2D, HotspotInspect
    - HotspotInspect: 클릭 시 CloseupViewer.Open(문 클로즈업 스프라이트)
    - (Core/UI/CloseupViewer) Close On Click=On, Close On Esc=On 권장
  - 자식 Chain: Create Empty → Add Component: BoxCollider2D, ChainUnlock
    - ChainUnlock.requiredClicks = 3(예시)
    - ChainUnlock.targetToEnable = DoorMove
    - ChainUnlock.OnUnlocked → (추가 액션 필요 시 연결)
  - 자식 DoorMove: Create Empty → Add Component: BoxCollider2D, HotspotMove (초기 비활성)
    - ChainUnlock.Unlocked 시 DoorMove.SetActive(true)
- Services/StageRoot
  - 생성 경로: GameObject > Create Empty (이름: StageRoot)
  - Add Component: StageRoot

3) 인스펙터 설정(실제 인스펙터 순서)
- World/BG (2D/Sprite)
  - Transform: 기본값
  - Sprite Renderer
    - Sprite = <배경 스프라이트>
    - Draw Mode = Simple
  - 참고: UI/Image 대체는 특수 케이스에서만 사용

- Interaction/Hotspots/DoorZoom (Empty)
  - Transform: 클릭 영역 위치/크기에 맞게 조정
  - Box Collider 2D
    - Is Trigger = Off(기본)
    - Size = 환경에 맞게 설정
  - Hotspot Inspect(스크립트)
    - Closeup Sprite = 문 클로즈업 이미지
    - (입력) InputService가 필요. Core 씬에 존재해야 함

- Interaction/Hotspots/Chain (Empty)
  - Transform: 문 중앙 체인 영역에 맞게 조정
  - Box Collider 2D: Size/위치 조정
  - ChainUnlock(스크립트)
    - Required Clicks = 3(예시)
    - OnUnlocked → DoorMove.SetActive(true)

- Interaction/Hotspots/DoorMove (Empty)
  - Transform: 문 영역
  - Box Collider 2D
    - Is Trigger = Off
  - Hotspot Move(스크립트)
    - Target Stage Id = "Stage2"
  - 초기 상태: SetActive(false)

- Services/StageRoot (Empty)
  - Transform: 기본값
  - StageRoot(스크립트) = 기본값

4) Components & Wiring(참조/이벤트 배선)
- FrontDoor 클릭 → HotspotMove가 StageChangeRequested("Stage_Lobby") 발행
- (UI 대체) UI Button OnClick → GameEvents.RaiseStageChangeRequested("Stage_Lobby")
  - Button 자식에 TextMeshProUGUI 라벨 배치(가이드 5.3 권장값)
