Title: Stage2 - Lobby - Hierarchy & Wiring Guide
SceneName: Stage2
Purpose: 로비 장면(왕복 이동/상호작용 기반)

1) 하이라키어 최종 구조도
- World_Empty(-)
  - BG_2D/Sprite(SpriteRenderer)
- Interaction_Empty(-)
  - Hotspots_Empty(-)
    - BackDoor_Empty(HotspotMove, BoxCollider2D)
- UI_Empty(-)
  - MainCanvas_UI/Canvas(Canvas, CanvasScaler, GraphicRaycaster)
- EventSystem_UI/Event System(-)
- Services_Empty(-)
  - StageRoot_Empty(StageRoot)

2) 하이라키어 제작 절차(생성 경로 포함)
- 컨테이너 생성: World, Interaction, Services
- World/BG: 2D Sprite 구성(기본). UI/Image 대체는 특수 케이스에서만 사용.
- Interaction/Doors
  - Door_Office: Create Empty → Add Component: BoxCollider2D, HotspotMove
  - Door_Delivery: Create Empty → Add Component: BoxCollider2D, DoorLocked, HotspotMove
- Interaction/Items
  - Cross/Permit: Create Empty → Add Component: BoxCollider2D, PickupItem
  - Letter: Create Empty → Add Component: BoxCollider2D, DocumentCloseup
- Interaction/Jumpscare
  - CounterGhost: Create Empty → Add Component: BoxCollider2D, JumpscareTrigger
- Services/StageRoot: Create Empty → Add Component: StageRoot

3) 인스펙터 설정(핵심 값)
- Doors/Door_Office
  - BoxCollider2D: 크기=문 영역
  - HotspotMove.targetStageId = "Stage_Office"
- Doors/Door_Delivery
  - BoxCollider2D: 크기=문 영역
  - DoorLocked.requiredItemId = ItemIds.KeyBundle
  - HotspotMove.targetStageId = "Stage_Delivery"
- Items/Cross
  - PickupItem.itemData = (Cross)
- Items/Permit
  - PickupItem.itemData = (License)
- Items/Letter
  - DocumentCloseup.documentItem = (AccidentLetter)
- Jumpscare/CounterGhost
  - JumpscareTrigger.triggerOnClick = true
  - JumpscareTrigger.sfx = (점프스케어 사운드)

4) Components & Wiring(참조/이벤트 배선)
- Door_Office: HotspotMove → Stage_Office
- Door_Delivery: DoorLocked(ItemIds.KeyBundle) → HotspotMove(Stage_Delivery)
- Items/*: PickupItem 또는 DocumentCloseup → CloseupViewer(옵션)
- Jumpscare/CounterGhost: 클릭 시 JumpscareTrigger.Fire()

5) Build Settings(Scenes In Build)
- Core, MainMenu, Stage1, Stage2, Stage_Office, Stage_Delivery 등록

6) Tests(기능 검증)
- Door_Office 이동 OK
- 키 획득 전 Door_Delivery 차단 → 키 획득 후 통과
- 문서 클로즈업 노출 OK, 점프스케어 사운드/비주얼 1회 발동

7) 체크리스트
- [ ] DoorLocked.requiredItemId = ItemIds.KeyBundle
- [ ] PickupItem.ItemData 연결(Cross/License)
- [ ] DocumentCloseup.ItemData 연결(AccidentLetter)
- [ ] Build Settings 등록

8) FAQ(문제 해결)
- 클릭 불가: Collider2D/레이어/카메라, UI 위 클릭 여부 확인
- 진행 불가: 키 아이템 미획득 여부 확인
