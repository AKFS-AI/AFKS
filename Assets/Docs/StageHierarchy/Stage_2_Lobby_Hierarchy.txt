Title: Stage2 - Lobby - Hierarchy & Wiring Guide
SceneName: Stage2
Purpose: 로비(월드 스프라이트 상호작용 기반)

1) 하이라키어 최종 구조도(월드 모드)
- World_Empty(-)
  - BG_2D/Sprite(SpriteRenderer)
- Interaction_Empty(-)
  - Doors_Empty(-)
    - Door_Office(HotspotMove, BoxCollider2D)
    - Door_Delivery(DoorLocked, HotspotMove, BoxCollider2D)
  - Items_Empty(-)
    - Cross(PickupItem, BoxCollider2D)
    - License(PickupItem, BoxCollider2D)
    - AccidentLetter(DocumentCloseup, BoxCollider2D)
  - Jumpscare_Empty(-)
    - CounterGhost(JumpscareTrigger, BoxCollider2D)
- Services_Empty(-)
  - StageRoot_Empty(StageRoot)

2) 제작 절차(요약)
- 컨테이너 생성 → BG 스프라이트 배치 → 각 문/아이템에 콜라이더와 스크립트 부착

3) 인스펙터 설정
- Door_Office: HotspotMove.targetStageId = "Stage_Office"
- Door_Delivery: DoorLocked.requiredItemId = ItemIds.KeyBundle, HotspotMove.targetStageId = "Stage_Delivery"
- Cross/License: PickupItem.itemData 연결
- AccidentLetter: DocumentCloseup.documentItem 연결
- CounterGhost: JumpscareTrigger.triggerOnClick = true

4) Wiring
- Door_Office → Stage_Office, Door_Delivery(키 필요) → Stage_Delivery
- Items → Inventory/Closeup(필요 시)

5) Build Settings
- Core, MainMenu, Stage1, Stage2, Stage_Office, Stage_Delivery 등록

6) Tests
- 오피스 이동, 키 획득 전/후 분만실 이동 제어, 문서 클로즈업, 점프스케어 1회 발동 확인

7) 변경 이력
- v2.0: 월드 스프라이트 우선으로 재정리
