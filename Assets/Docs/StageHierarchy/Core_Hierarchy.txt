Title: Core - Hierarchy & Wiring Guide
SceneName: Core
Purpose: 전역 서비스/전역 UI 상주, 스테이지(Stage_*) 애디티브 전환의 기반

Hierarchy (추천)
- Core (empty)
  - SceneService (SceneService)
  - FadeCanvas (Canvas + Image + CanvasGroup)
  - StartupLoader (StartupLoader)
  - [Optional] EventSystem (EventSystem + InputModule)
  - [Optional] AudioService (AudioService)
  - [Optional] SaveServiceBootstrap (초기 로드/저장 트리거용 빈 오브젝트)

Components & Wiring
- SceneService
  - 역할: StageChangeRequested 구독 → Fade.Out → LoadAdditive(next) → Activate → Unload(prev) → Fade.In
  - 필드: defaultFadeSeconds = 0.6 (권장)
- FadeCanvas
  - Canvas: Screen Space - Overlay, Sorting Order 가장 위
  - Image: Black(#000), Stretch(Full)
  - CanvasGroup: alpha=0, blocksRaycasts=false, interactable=false
  - 사용: 전환 중 alpha 1.0, blocksRaycasts true로 입력 차단
- StartupLoader
  - initialStageId = Stage_Front (또는 Stage_Menu)
  - autoLoadOnStart = true
- [Optional] EventSystem
  - UI 상호작용 안전 장치(메뉴/모달 대비)
- [Optional] AudioService
  - BGM/SFX 최소 재생 및 크로스페이드(후속 단계 연결)
- [Optional] SaveServiceBootstrap
  - 게임 시작 시 세이브 로드 → 옵션/볼륨 반영(후속 단계 연결)

Build Settings
- Core.unity를 목록 최상단에 배치(항상 상주)
- Stage_* / Stage_Menu 씬은 애디티브 로드 대상

Notes
- Core는 한 번만 초기화되며 전환 내내 유지됩니다.
- DontDestroyOnLoad를 별도 사용하지 않아도 Core 씬이 언로드되지 않도록 구성합니다.
- 전환 실패 시 이전 스테이지 유지 + 페이드 해제 + 로그로 처리합니다.

Quick Test (MVP)
1) Core 열기 → Play → StartupLoader가 Stage_Front 요청
2) Stage_Front에서 HotspotMove로 Stage_Office 이동
3) 왕복 전환 5회: 페이드/언로드/입력차단 정상 여부 확인

초보자용 단계별 가이드 (하이라키 + 인스펙터)
1) 씬 생성: File > New Scene → 저장 이름 `Core.unity`
2) 하이라키 만들기
- Core (Empty)
  - FadeCanvas (Canvas + Image + CanvasGroup + FadeCanvas)
  - SceneService (SceneService)
  - StartupLoader (StartupLoader)
  - EventSystem (EventSystem, 선택)
3) 인스펙터 설정
- FadeCanvas(Canvas)
  - Render Mode: Screen Space - Overlay, Sorting Order: 1000
  - CanvasScaler: Scale With Screen Size, Reference 1920x1080, Match 0.5
  - Image: Color #000000, Alpha 1.0, RectTransform Stretch(모두 0)
  - CanvasGroup: Alpha 0, Interactable Off, Blocks Raycasts Off
  - FadeCanvas(스크립트): 기본값 사용
- SceneService
  - Default Fade Seconds: 0.6 (권장)
  - FadeCanvas: 위 FadeCanvas를 드래그하여 참조 연결
- StartupLoader
  - Initial Stage Id: `Stage_Menu` (또는 `Stage_Front`)
  - Auto Load On Start: On
- EventSystem(선택)
  - EventSystem 컴포넌트만 있어도 OK
4) 빌드/실행 준비
- Build Settings에 Core를 최상단으로, Stage_Menu / Stage_Front 추가
5) 실행 확인
- 재생 → StartupLoader가 Initial Stage를 요청 → SceneService가 페이드/로드/언로드/페이드 수행
