Title: Core - Hierarchy & Wiring Guide (with Pause/Save)
SceneName: Core
Purpose: 전역 서비스/이벤트/페이드/ESC 메뉴를 제공

1) 최종 하이라키
- Systems_Empty(-)
  - SceneService(Service)
  - InputService(Service)
  - AudioService(Service)
  - SaveService(Service) [DontDestroyOnLoad]
  - FadeCanvas(UI)
  - PauseMenuCanvas(UI/Canvas + PauseMenuController)

2) 제작 절차
- Systems_Empty 생성
- SceneService/InputService/AudioService/SaveService/FadeCanvas 배치
- PauseMenuCanvas 생성
  - Canvas(RenderMode=Overlay, SortingOrder 높음)
  - CanvasGroup + PauseMenuController
  - Buttons: Resume/Save&Quit/Quit
  - Sliders: Master/BGM/SFX → PauseMenuController에 연결

3) 이벤트
- GameEvents.PauseToggled(bool) 발행: PauseMenuController가 토글 시 전역 구독자 반응 가능
- StageLoaded/Unloaded/ChangeRequested: 기존 유지

4) Build Settings
- Core, MainMenu, Stage1, Stage2 등록

5) 체크리스트
- [ ] SaveService가 Core 씬에 1개 존재하고 DontDestroyOnLoad
- [ ] PauseMenuCanvas 비활성 시작, ESC로 토글
- [ ] 오디오 볼륨 슬라이더 조정 시 저장 반영
