[AFKS] 씬 구성 정보 (원클릭 자동화 기준)

1) 공통 규약
- 모든 씬은 원클릭 마법사 실행 시 하이라키가 멱등하게(기존 유지, 누락 보강) 구성된다.
- 배경 이미지는 Sprite(2D and UI)로 임포트하고, 각 Stage 씬의 Background(SpriteRenderer)에 수동 할당한다.
- 오디오는 AudioDatabase.asset에 id-clip 매핑으로 연결한다. (예: lock_click, chain_break, amb_lobby)
- 화면 입력 판정은 카메라 없이도 동작(스크린 비율 기준)하므로 카메라 유무와 관계없이 클릭 테스트 가능.

2) 씬 목록
- MainCore.unity: 전역 런타임(게임 플레이 씬)
- MainMenu.unity: 메뉴(UI만)
- Stage1.unity ~ Stage6.unity: 스테이지 프리뷰/에디팅용(실행도 가능)

3) MainCore.unity 하이라키 (자동 생성)
- GameRuntime (DontDestroyOnLoad)
  - Components:
    - AFKS.Core.Composition.GameRuntime
    - 내부에서 다음 시스템/서비스가 활성화됨
      * Services: EventBus, InventoryService, ProgressService, SaveService
      * Systems: StageController, InteractionSystem, SequenceSystem, ZoomView, AudioSystem, JumpscareSystem
  - Serialized Fields(에디터에서 자동 주입)
    - _uiCamera: UICamera
    - _uiCanvas: UICanvas
    - _uiRoot:   UICanvas(RectTransform)
    - _projectConfig: Assets/Data/Hospital/ProjectConfig.asset
    - _audioDatabase: Assets/Data/Hospital/AudioDatabase.asset
- UICamera (Camera)
  - clearFlags: Depth, orthographic: true, depth: 100
- UICanvas (Canvas + CanvasScaler + GraphicRaycaster)
  - RenderMode: ScreenSpaceCamera, WorldCamera: UICamera
  - 자식: ZoomView(런타임 생성), StageOverlay(스테이지 로드시 생성)
- EventSystem (EventSystem + StandaloneInputModule)
- StageRoot (빈 GameObject)
  - Background (SpriteRenderer)
  - Hotspot_* (필요 시 여러 개) — 에디터가 기본 1개 생성

4) StageX.unity 하이라키 (자동 생성)
- GameRuntime
  - 동일한 구성/필드 자동 주입(상동)
- UICamera / UICanvas / EventSystem (상동)
- InventoryService (AFKS.Core.Mono.InventoryServiceComponent)
- ProgressService (AFKS.Core.Mono.ProgressServiceComponent)
- StageRoot
  - Background (SpriteRenderer) — 스테이지 배경 Sprite 수동 지정
  - Hotspot_front_gate (AFKS.Core.Mono.HotspotRect)
    * id: front_gate_chain
    * rect: x=0.45, y=0.38, w=0.10, h=0.22 (뷰포트 비율)
    * goToStageIndex: 필요 시 설정(-1이면 유지)

5) MainMenu.unity 하이라키 (자동 생성)
- GameRuntime (동일)
- UICamera / UICanvas / EventSystem (동일)
- StageRoot (선택)
  - Background (선택)
- 버튼/텍스트 등 메뉴 UI는 UICanvas 하위에 배치. 시작 버튼 → MainCore로 진입(또는 ProjectConfig 첫 스테이지 로드 호출).

6) 컴포넌트/스크립트 배치 기준
- GameRuntime: 전역 Composition Root. Awake에서 서비스/시스템을 연결하고 첫 스테이지를 로드.
- InventoryServiceComponent / ProgressServiceComponent: 씬 가시 오브젝트로 서비스 상태를 확인·노출.
- HotspotRect: 씬에 베이크되는 정규화 클릭 영역 정의. InteractionSystem이 우선 사용.
- Background(SpriteRenderer): 스테이지 배경 스프라이트를 표시. 정적 이미지 사용 권장(흑백 톤).

7) 데이터 에셋
- Assets/Data/Hospital/ProjectConfig.asset
  - stages[]: 스테이지 SO들을 순서대로 등록
  - audio: AudioDatabase.asset 연결
- Assets/Data/Hospital/AudioDatabase.asset
  - entries[]: id(string) - clip(AudioClip)
- (선택) Assets/Data/Hospital/Stages/Stage_*.asset
  - StageDefinition: overlays/hotspots/zooms/gimmicks 정의(씬 베이크 핫스팟 대신 SO 사용 가능)

8) 시퀀스(연출) 동작 흐름
- 클릭 시 → InteractionSystem가 HotspotRect(or StageHotspot) 히트 → Hotspot에 sequence가 있으면 SequenceSystem이 처리
- Sequence Action 예시: SetFlag, PlaySfx, ShowZoom, ToggleOverlay, GoToStage
- 예: Stage1 정문 체인
  * 클릭1: lock_click + gate_zoom 표시
  * 클릭3: chain_strain
  * 클릭4: chain_broken 토글 + chain_break + Flag(GateChainBroken)
  * 클릭5: 조건(Flag) 만족 시 Stage 2로 이동

9) 제작 순서(권장)
- 원클릭 설정 마법사 실행 → Assets/Scenes 전 씬 자동 보강
- 각 Stage 씬 열기 → Background(Sprite 지정), HotspotRect 여러 개 배치/수정
- AudioDatabase에 SFX/BGM id-clip 등록
- 필요 시 StageDefinition(SO)로 오버레이/줌/기믹을 정의하고 ProjectConfig에 stages[] 등록
- Play로 검증 → 시퀀스/플래그/사운드 튜닝

10) 멱등/재실행 규칙
- 이미 존재하는 오브젝트/컴포넌트/필드는 변경하지 않음(누락만 생성)
- 씬을 수동 편집한 뒤에도 마법사를 재실행하면 안전하게 보강된다

11) 네이밍/정렬 가이드
- 씬 루트: GameRuntime, UICamera, UICanvas, EventSystem, StageRoot, InventoryService, ProgressService
- 핫스팟: Hotspot_* (의미 있는 id 사용), rect는 0..1 범위 비율 좌표로 정의
- 오디오 id: 소문자+언더스코어 권장(lock_click, chain_break, amb_lobby)

13) 스테이지 세부 스펙(정밀 기획)

— 공통 규칙
- Rect 좌표는 뷰포트 비율(x, y, w, h). 실제 배경에 맞춰 미세 조정.
- 시퀀스 표기: [클릭횟수] 액션들(조건) → 결과/전환
- 아이템 획득은 Zoom의 canPickupItemId 또는 시퀀스 액션으로 지급.
- Jumpscare는 쿨다운 1.5s, 입력블록 0.3s 기본.

Stage 1: 병원 앞(정문)
- 목표: 정문 체인 파괴 후 로비 진입
- 배경: Background_FrontGate (흑백, 대비↑, 비네트)
- 오버레이: chain_full(초기 on), chain_broken(초기 off)
- 핫스팟
  1) front_gate_chain (0.45,0.38,0.10,0.22)
     - [1] PlaySfx(lock_click), ShowZoom(gate_zoom)
     - [3] PlaySfx(chain_strain)
     - [4] ToggleOverlay(chain_full=false), ToggleOverlay(chain_broken=true), PlaySfx(chain_break), SetFlag(GateChainBroken)
     - [5] if Flag(GateChainBroken) → GoToStage(2)
- 줌: gate_zoom(캡션: 녹슨 체인…)
- SFX: lock_click, chain_strain, chain_break, amb_front

  - cross (0.32,0.52,0.06,0.10): showZoom=cross_zoom, canPickupItemId=cross
  - permit (0.58,0.48,0.08,0.12): showZoom=permit_zoom, canPickupItemId=permit
