# 📚 AFKS 게임 개발 문서

## 🎯 개요

**AFKS (A Fear Keeps Silence)**는 Unity로 제작되는 2D 호러 어드벤처 게임입니다.  
이 문서들은 게임을 처음부터 완성까지 단계별로 개발하는 방법을 상세히 안내합니다.

## 🎮 게임 특징

### 🎯 **핵심 게임플레이**
- **점-앤-클릭 어드벤처**: 직관적인 마우스 상호작용
- **스테이지 기반 진행**: 순차적 스토리 진행
- **아이템 수집**: 열쇠, 손전등 등 필수 아이템
- **호러 요소**: 적절한 긴장감과 분위기

### 🔧 **기술적 특징**
- **모듈형 아키텍처**: 독립적인 시스템 설계
- **이벤트 기반 통신**: 시스템 간 느슨한 결합
- **고급 상호작용**: 줌, 멀티클릭, 픽셀 퍼펙트 등
- **확장 가능한 구조**: 새로운 스테이지와 기능 쉽게 추가

## 🛠️ 구현된 시스템들

### 🎮 **핵심 시스템**
| 시스템 | 클래스 | 기능 |
|--------|--------|------|
| **게임 관리** | `GameManager` | 전체 게임 상태, 성능 모니터링 |
| **씬 관리** | `SceneController` | 씬 전환, 로딩 화면 |
| **스테이지 관리** | `StageManager` | 스테이지 데이터, 진행도 |
| **오디오 관리** | `AudioManager` | BGM, SFX, 크로스페이드 |
| **UI 관리** | `UIManager` | 패널 전환, UI 애니메이션 |
| **아이템 관리** | `ItemManager` | 열쇠, 손전등 수집/사용 |

### 🖱️ **상호작용 시스템**
| 타입 | 클래스 | 사용 용도 |
|------|--------|----------|
| **기본 상호작용** | `StageInteractionController` | 일반적인 클릭 상호작용 |
| **2단계 상호작용** | `TwoStageInteractionController` | 확대 → 세부 상호작용 |
| **픽셀 퍼펙트** | `PixelInteractionController` | 정밀한 클릭 영역 설정 |
| **줌 시스템** | `ZoomController` | 이미지 확대/축소 |

### 👻 **호러 시스템**
- **HorrorEventManager**: 호러 이벤트 관리
- **다양한 트리거**: 시간, 상호작용, 조건부 발동
- **점프스케어**: 이미지, 사운드, 화면 흔들기
- **분위기 조성**: 환경음, 랜덤 이벤트

## 🎨 필요한 에셋

### 🖼️ **이미지 에셋**
```
배경 이미지:
├── 병원 외부 (1920x1080)
├── 병원 로비 (1920x1080)
└── 추가 스테이지 배경들

상호작용 이미지:
├── 병원 철문 (800x600)
├── 쇠사슬 (300x200)
├── 리셉션 데스크 (300x200)
└── 의료 캐비닛 (200x300)

UI 요소:
├── 버튼 (9-slice 가능)
├── 패널 배경
├── 아이콘들 (아이템, 상태 등)
└── 호러 이미지들 (점프스케어용)
```

### 🎵 **오디오 에셋**
```
BGM:
├── 메인메뉴 음악 (밝고 긴장감 있는)
├── 게임플레이 음악 (어둡고 불안한)
└── 각 스테이지별 테마 음악

효과음:
├── 버튼 클릭
├── 문 열기/닫기
├── 쇠사슬 부딪치는 소리
├── 아이템 획득
├── 호러 효과음 (비명, 쿵 소리 등)
└── 환경음 (바람, 기계음 등)
```

## ✅ 기능 완성도 체크리스트

### 🎮 **기본 기능** (필수)
- [ ] **메인메뉴**: 게임 시작, 설정, 종료 버튼
- [ ] **씬 전환**: 부드러운 로딩 화면과 함께
- [ ] **스테이지 시스템**: 순차적 진행 구조
- [ ] **기본 상호작용**: 클릭으로 상호작용
- [ ] **아이템 시스템**: 수집 및 사용
- [ ] **오디오 시스템**: BGM과 효과음
- [ ] **UI 시스템**: 인벤토리, 메시지 표시

### 🚀 **고급 기능** (확장)
- [ ] **2단계 상호작용**: 확대 → 세부 클릭
- [ ] **줌 시스템**: 부드러운 확대/축소
- [ ] **픽셀 퍼펙트 클릭**: 정밀한 상호작용
- [ ] **호러 이벤트**: 점프스케어, 분위기 연출
- [ ] **성능 최적화**: 메모리 관리, 로딩 최적화
- [ ] **접근성**: 키보드 지원, 설정 옵션

### 🎯 **게임 완성도** (최종)
- [ ] **완전한 스토리**: 시작부터 끝까지
- [ ] **밸런싱**: 적절한 난이도와 진행 속도
- [ ] **버그 없음**: 모든 기능 정상 작동
- [ ] **사용자 경험**: 직관적이고 만족스러운 플레이
- [ ] **빌드 최적화**: 배포 가능한 상태
