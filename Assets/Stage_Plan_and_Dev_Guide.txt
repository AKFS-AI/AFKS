0.2 필수 스크립트(8개)

0.3 에디터 배선(5단계)
1) Build Settings: Core, Stage_Front, Stage_Office 등록(순서 맨 위 Core)
2) Core 씬: SceneService 오브젝트 추가, Canvas+Black Image+FadeCanvas 추가, StartupLoader 추가(initialStageId=Stage_Front)
3) Stage_Front: BG 배치, 정문 오브젝트에 HotspotMove(target=Stage_Office), StageRoot 추가
4) Stage_Office: BG 배치, 되돌아가기 오브젝트에 HotspotMove(target=Stage_Front), StageRoot 추가
5) 재생: Front↔Office 전환 확인(페이드/언로드 정상)

0.4 리소스 최소 수량

0.6 성능/품질 최소 기준

1. 개요(비전·원칙·범위)
- 러닝타임: 약 20분, 점프스케어 5회, 클로즈업 아이템 10개
- 톤앤매너: 19~20세기 흑백 사진풍, 포인트 레드 최소
- 기술: Unity 6000.0.42f1, URP 2D(Renderer2D), 2D 파이프라인
- 구조: Core 상주 + Stage_* 씬 애디티브 교체(상태/설정/서비스 유지)
- 성능 목표: 60FPS, 프레임당 GC 0, 전환 < 1.5s
- 입력: New Input System 단일 액션맵, 게임 코드는 IInputService만 참조
- 저장: JSON + 버전 필드, 마이그레이션 함수 유지(손상 시 롤백)




1.1 제작 원칙/스코프 가드
- 스테이지 수: 5~6(축소 필요 시 Front∪Lobby 병합). 목표 러닝타임 20분
- 연출 예산: 점프스케어 5, 클로즈업 아이템 10
- 반복 가능한 전환 파이프라인/입력잠금/세이브 안전성 우선

2. 아키텍처(씬 전략·폴더·스크립트 구조·전환 FSM·지속성 정책)
2.1 씬 전략 및 목록
- Core(상주)
- Stage_Menu(메인 메뉴), Stage_Front(병원 앞), Stage_Lobby(병원 로비), Stage_Office(관리실), Stage_Delivery(분만실), Stage_Nursery(신생아실), Stage_Chapel(기도실)
- 전환 순서: 입력잠금 → 페이드아웃 → 다음 스테이지 애디티브 로드(프리로드 옵션) → 활성화/초기화 → 이전 스테이지 언로드 → BGM 크로스페이드 → 페이드인 → 입력해제
- 실패 시 롤백: 이전 유지 + 사용자 피드백 + 로그

2.2 폴더/애셋 구조
- Assets/Scenes/: Core.unity, Stage_*.unity
- Assets/Art/Stages/Stage_<Name>/: BG/, Hotspots/, Atlas/<Name>.spriteatlas
- Assets/Audio/{BGM|SFX}/
- Assets/Configs/{Stages|Hotspots|Items|JumpScare}/
- Assets/Prefabs/{UI|Stage}/
- Assets/Scripts/Core/{Services|Systems|Events|Utils}/
- Assets/Scripts/Features/{Stage|Interaction|Inventory|CloseUp|JumpScare|Cutscene|Menu}/

2.3 스크립트 구조(개요)
- Core/Services: ServiceLocator, InputService, SceneService, AudioService, SaveService(+PoolService)
- Core/Systems: TickService(단일 업데이트), GameStateMachine(Boot→Menu→InGame→Transition)
- Core/Events: GameEvents(StageChange/Interaction/ItemPicked/JumpScare 등)
- Features: StageRoot/Configs, Interaction, Inventory, CloseUp, JumpScare, Cutscene, Menu

2.4 전환 FSM(요약)
- Idle → FadingOut → LoadingNext → Activating → UnloadingPrev → FadingIn → Idle
- Guards: 입력잠금 on/off, 로드/활성/언로드 완료 확인
- Fail Path: 로드 실패 → Rollback(이전 유지) → 토스트/로그 → Idle

2.5 지속성 정책(Core 유지/Stage 초기화)
- Core 유지: Input/Scene/Audio/Save/Tick, GameEvents, 인벤토리/진행/설정, UI(Fade/Pause/Settings), 오디오 믹서/볼륨, GameState
- Stage 초기화: Stage_* 오브젝트(배경/핫스팟/연출), StageRoot.Initialize()로 프리셋/트리거 재세팅, Teardown()로 임시 리소스·구독 정리
- 금지: 스테이지 스크립트의 static 전역 상태(서비스/세이브로 관리 대체)

3. 데이터·리소스(스키마·스테이지별 계획·아트/오디오 가이드)

3.2 스테이지별 설계(리소스·기믹·아이템·연출)

  - 아이템: 휴대용 십자가, 병원 개설 허가증, 바닥의 사고 편지(클로즈업)
  - 리소스: BG, 문 오브젝트, 하이라이트, 클릭 SFX, 실내 앰비언스
- Stage_3 / Stage_Office(관리실)
  - 기믹: CCTV 불켜짐 + 귀신 갑툭튀, 문서 열람, 열쇠 꾸러미 획득→Delivery 해금 플래그
  - 아이템: 사건사고 서류, 병원 단면도(클로즈업), 열쇠 꾸러미(들고가는 아이템)
  - 리소스: BG, CCTV 모니터, 문서/단면도 클로즈업, 점프스케어 SFX

  - 아이템: 초음파 사진(클로즈업)
  - 리소스: BG, 심전도/침대/초음파 소품, 비명/아기 울음 SFX
- Stage_5 / Stage_Nursery(신생아실)
  - 기믹: 인큐베이터 다수 중 1개만 열림, 아기 귀신 얼굴 점프스케어
  - 아이템: 오르골, 혈액 검사 자료(클로즈업), 쪽지(양심 고백, 클로즈업)

- Stage_6 / Stage_Chapel(기도실)
  - 기믹: 제단에서 의식 연출, 아이 실루엣, 병원장 시체 점프스케어
  - 아이템: 기도문(클로즈업), 병원 개원 사진(클로즈업)
  - 리소스: BG, 제단 3슬롯(십자가/열쇠/오르골)

6. 품질·성능(체크리스트·성능 예산·프로파일링·에러/로그·코드 최적화)
6.1 품질/성능 체크리스트
- 입력 단일 통로(IInputService), 전환 중 입력 완전 차단, 이벤트 구독/해제 준수
- 핫패스: LINQ/foreach/박싱/프레임당 할당 금지, 풀 사용, 캐시 참조
- 로그: Log.Info/Warn/Error 유틸만, 예외는 상위에서 집계/보고
- 전환 후 UnloadUnusedAssets는 페이드 중 수행, 왕복 50회 스트레스에서 GC/누수 0

 

6.2 에러 처리·로그 정책
- Info: 상태 전환/사용자 행동, Warn: 비치명 결손, Error: 전환 실패/데이터 손상
- 사용자 피드백: 실패/조건 미충족 시 토스트와 재시도 안내
- 수집: 빌드 버전/스테이지 ID/최근 이벤트 로그 파일화(경로는 Readme에 표기)

6.3 코드 정확성/최적화 가이드
- 가드 우선(널/범위)·조기 반환; try/catch 최소, 빈 catch 금지
- 전역 상태는 Core 서비스로만; 스테이지 static 금지
- 데이터는 SO로 분리, 런타임 생성 최소, 포스트/오디오/카메라 파라미터 캐시 적용

8.2 인터페이스/서비스(코어)
- IInputService / InputService
  - 책임: 포인터 좌표/클릭, UI 오버 판정, 입력 잠금(우선순위: Transition > Modal > CloseUp > World)
  - API: IsLocked, PointerPosition, event Clicked, Lock(bool), IsPointerOverUI()
- ISceneService / SceneService
  - 책임: 스테이지 전환(애디티브 Load/Activate/Unload) + 페이드 훅 + 입력잠금 제어
  - API: LoadStageAdditiveAsync(id, preload), ActivateLoadedStageAsync(id), UnloadStageAsync(id), FadeOutAsync(sec), FadeInAsync(sec)
- IAudioService / AudioService
  - 책임: BGM 2채널 크로스페이드, SFX OneShot, 볼륨/DR 적용(추후 Mixer 파라미터)
  - API: PlayBGM(clip), CrossFadeBGMAsync(clip,sec), PlaySFX(clip,vol), SetVolume(master,bgm,sfx), SetDynamicRange(bool)
- ISaveService / SaveService(JSON v1)
  - 책임: 저장/로드(+버전/백업), 진행(currentStageId)/오디오/접근성/플래그/인벤토리
  - 스키마: version, currentStageId, inventory[], flags[], audio{}, accessibility{}
- ServiceLocator
  - 책임: Register/Unregister/Get/TryGet 단일 진입점

8.3 시스템/이벤트/UI(코어)

- GameStateMachine: Boot→Menu→InGame→Transition 상태 전환
- GameEvents: StageChangeRequested/Loaded/Unloaded (+ ItemPicked/JumpScareTriggered 확장 여지)
- UI: FadeCanvas(CanvasGroup), SettingsPanel, PauseMenu

8.4 피처 스크립트
- StageIds: Stage_Front/Lobby/Office/Delivery/Nursery/Chapel/Menu
- StageRoot: Initialize()/Teardown() 훅, 진입/종료 정리
- StageConfig(SO): stageId, sceneName, bgm, initialHotspotIds[]
- HotspotConfig(SO): hotspotId, type{Move|Inspect|Use}, targetStageId?, requiredFlag?, setFlagOnSuccess?, itemId?, tooltip
- ItemConfig(SO): itemId, displayName, closeUpSprite?, usableTargets[]
- InteractionController: 레이캐스트→IInteractable, 하이라이트/커서, 클릭 전달
- IInteractable / InteractableBase: CanInteract(), OnInteract()
- HotspotMove/Inspect/Use: 이동/클로즈업/사용(플래그·아이템 가드)
- InventoryService / InventoryUI: 6슬롯, 드래그-투-유즈, ItemPicked 이벤트
- CloseUpController: Open/Close, Modal 잠금
- JumpScarePlayer: 시퀀스, 입력잠금 윈도우, 오디오 모노 다운/복원
- TimelineTrigger: 스테이지 한정 연출

8.5 작동 플로우(요약)
- 스테이지 전환: HotspotMove/MainMenuUI → GameEvents.StageChangeRequested →
  SceneService: Input.Lock(Transition) → Fade.Out → LoadAdditive(next) → Activate → StageRoot.Initialize →
  Unload(prev) → Audio.CrossFade → Fade.In → Input.Unlock
- 인터랙션: InteractionController Raycast → IInteractable.CanInteract → OnInteract
  - Inspect: CloseUp.Open → Modal Lock → Close 시 복원
  - Use: Inventory 검사 → 성공 시 플래그/상태 변경
- 점프스케어: Trigger → JumpScarePlayer.Play → Input.Lock(window) → Audio 모노 다운 → 시퀀스 → 복원

8.6 구현 순서(코드)
- Step1(Core): ServiceLocator, GameEvents, FadeCanvas, SceneService(스텁), InputService(스텁), SaveService(JSON v1), AudioService(간이)
- Step2(Stage 1→2): Stage_Front/Stage_Lobby 씬 + StageRoot + HotspotMove + InteractionController(간소)
- Step3(Stage 2→3): Lobby 아이템/플래그(십자가/허가증/편지) + Office CCTV 점프스케어 + 열쇠 꾸러미→DeliveryUnlocked
- Step4(Stage 4~6): Delivery/Nursery/Chapel 연출, CloseUp/Inventory/JumpScare 확장, Save 스키마 확장

 

부록 A. 2D 파이프라인 필수 체크리스트
- URP 2D(Renderer2D), Global Volume, Ortho 카메라, Pixel Perfect(필요 시), Sorting Layers(BG/Hotspot/FX/UI)
- 스프라이트 임포트: MipMap Off, Read/Write Off, Compression High(필요 시 None), MaxSize 규격화, 스테이지별 아틀라스
- 품질: VSync Off, targetFrameRate 60, Physics2D/Time 설정 정리
- 코어: Scene/Audio/Input/Save/Tick 상주, GameEvents 브로드캐스트, 핫패스 무할당·무LINQ·무박싱
- UI/오디오: 페이드/모달, 커서 3종, 믹서 Master/BGM/SFX, BGM 크로스페이드, 라우드니스 안전값

부록 B. 핵심 인터페이스 시그니처(비구현)
- IInputService: Lock(bool), IsPointerOverUI(), PointerPosition, event Clicked
- ISceneService: LoadStageAdditiveAsync(stageId, preload), ActivateLoadedStageAsync(stageId), UnloadStageAsync(stageId), FadeOutAsync(sec), FadeInAsync(sec)
- IAudioService: PlayBGM(clip), CrossFadeBGMAsync(next, sec), SetVolume(master,bgm,sfx), SetDynamicRange(enabled), PlaySFX(clip)
- ISaveService: SaveAll(), TryLoadAll(), CurrentStageId, Audio/Accessibility 설정 프로퍼티
- GameEvents: StageChangeRequested/Loaded/Unloaded, InteractionRequested, ItemPicked
- StageRoot: Initialize(CoreRefs), Teardown()

부록 C. 전환 상태머신(FSM) 개요
- States: Idle → FadingOut → LoadingNext → Activating → UnloadingPrev → FadingIn → Idle
- Fail Path: 로드 실패 시 Rollback(이전 유지) + 토스트 + Log.Error

부록 D. 스크립트 상세 아키텍처(연결/역할/수명)
D.1 Core.Services(책임/의존성)
- ServiceLocator
  - 책임: 서비스 등록/조회 단일 진입점, 중복 등록 방지
  - 의존성: 없음(루트)
- InputService
  - 책임: 포인터 좌표, 클릭 이벤트, UI 오버 판정, 입력 잠금
  - 의존성: Unity Input System, UI(EventSystem)
  - 발행: Clicked, LockedChanged
- SceneService
  - 책임: 애디티브 로드/활성/언로드, 페이드 연동, 입력 잠금 제어
  - 의존성: InputService(잠금), AudioService(BGM), SaveService(현재 스테이지 갱신)
  - 발행: StageLoaded/StageUnloaded(GameEvents), 내부 FSM 상태 변경
- AudioService
  - 책임: BGM/SFX 재생, 크로스페이드, 볼륨/다이내믹레인지 적용, 점프스케어 모노 다운/복원
  - 의존성: Audio Mixer
- SaveService
  - 책임: JSON 저장/로드, 버전 관리/마이그레이션, 오디오/접근성/진행 보관
  - 의존성: 파일 IO
- PoolService(옵션)
  - 책임: VFX/UI 프롬프트 풀링, 생성/반환 단일 진입점
  - 의존성: 없음

D.2 Core.Systems
- TickService
  - 책임: 단일 업데이트 허브, 등록된 ITickable 갱신(남발 금지)
  - 의존성: 없음
- GameStateMachine
  - 책임: Boot→Menu→InGame→Transition 상태 전환, 전환 트리거 발행
  - 의존성: SceneService, SaveService

D.3 Features.Stage
- StageRoot(MonoBehaviour)
  - 책임: 스테이지 진입 초기화(카메라/후처리/초기 핫스팟/오디오), 종료 정리
  - 의존성: StageConfig, CoreRefs(서비스 핸들)
- StageConfig(SO), HotspotConfig(SO)
  - 책임: 데이터 보관/에디터 저작

D.4 Features.Interaction
- InteractionController(MonoBehaviour)
  - 책임: 레이캐스트→IInteractable 판정, 커서/툴팁, 클릭 시 OnInteract 호출
  - 의존성: InputService, CursorController, 레이어마스크
  - 구독: InputService.Clicked
- InteractableBase(MonoBehaviour)
  - 책임: 공통 하이라이트/툴팁/활성 조건, IInteractable 구현
- HotspotMove/Inspect/Use(MonoBehaviour)
  - Move: GameEvents.StageChangeRequested(targetStageId) 발행
  - Inspect: CloseUp.Open → 입력 잠금 → 닫기 시 복원
  - Use: Inventory 검사 → 성공 시 상태 변경/이벤트 발행
- CursorController
  - 책임: 커서 프리셋 적용(기본/인터랙트/금지)

D.5 Features.Inventory
- InventoryService
  - 책임: 아이템 보관/사용, 세이브 연동, 이벤트 발행(ItemPicked)
  - 의존성: SaveService
- InventoryUI
  - 책임: 슬롯 표시/드래그-투-유즈, 포커스 관리

D.6 Features.CloseUp
- CloseUpController/UI
  - 책임: 클로즈업 열기/닫기, 입력 포커스/잠금 제어, 확대 스프라이트 표시
  - 의존성: InputService

D.7 Features.JumpScare
- JumpScarePlayer
  - 책임: JumpScareClip 재생(스프라이트 시퀀스/카메라 흔들림/SFX/입력잠금 윈도우)
  - 의존성: AudioService, InputService
  - 발행: JumpScareTriggered(GameEvents)

D.8 Features.Menu
- MainMenuUI
  - 책임: New/Continue/Settings/Quit 버튼 처리
  - 의존성: SceneService, SaveService
- PauseMenuUI
  - 책임: Resume/Settings/Main/Quit, 월드 입력 잠금, BGM 덕킹
  - 의존성: InputService, AudioService, SceneService
- SettingsPanel
  - 책임: 오디오/접근성 옵션 적용, 세이브 커밋
  - 의존성: AudioService, SaveService

D.9 이벤트 매핑(발행/구독)
- GameEvents.StageChangeRequested: 발행=HotspotMove/MainMenuUI/StoryFlow, 구독=SceneService
- GameEvents.StageLoaded/Unloaded: 발행=SceneService, 구독=StageFlow/Analytics(Optional)
- GameEvents.InteractionRequested: 발행=InteractionController, 구독=해당 Interactable/StageScript
- GameEvents.ItemPicked: 발행=InventoryService, 구독=UI/퀘스트(있다면)
- GameEvents.JumpScareTriggered: 발행=JumpScarePlayer, 구독=Audio/Analytics(Optional)

D.10 주요 시퀀스 플로우
- 스테이지 전환
  1) HotspotMove → StageChangeRequested(target)
  2) SceneService: Input.Lock(true) → Fade.Out → LoadAdditive(target) → Activate → StageRoot.Initialize → Unload(prev) → Audio.CrossFade → Fade.In → Input.Lock(false)
- 인터랙션(이동 제외)
  1) InteractionController 레이캐스트 → 하이라이트 → 클릭 시 대상 IInteractable.OnInteract
  2) Inspect: CloseUp.Open → 입력 잠금 → 닫기 시 복원
  3) Use: Inventory 검사 → 성공 시 상태 변경/이벤트 발행
- 점프스케어
  1) Trigger → JumpScarePlayer.Play(clip) → Input.Lock(window) → Audio 모노 다운 → 시퀀스 재생 → 복원

D.11 수명주기/의존 규칙
- 의존 방향: Features → Core(Services/Events) 단방향. Core끼리 순환 금지
- MonoBehaviour 구독/해제: OnEnable/OnDisable 또는 Initialize/Teardown
- 데이터 소유: SO(정적), Save(영속), 런타임 서비스(가변). 스테이지 스크립트는 가변 상태 최소화

D.12 테스트 포인트
- 단위: InventoryService, SaveService, Audio 볼륨 적용, StageConfig 로딩
- 통합: 전환 파이프라인, Pause/Settings 모달, JumpScare 입력잠금
- 스트레스: 왕복 전환 50회, 빠른 연타, UI 오버
